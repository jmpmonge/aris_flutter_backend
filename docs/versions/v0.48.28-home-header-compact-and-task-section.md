# v0.48.28 — Compactación real de header HOY y microencabezado TAREAS

## 1. Contexto

v0.48.27 suavizó correctamente la línea vertical de eventos, pero no redujo de forma suficiente el espacio visual porque el header HOY mantenía una altura mínima elevada (`44 px` + cajetín chevron `44 px`).

## 2. Objetivo

- Reducir altura real del cajetín/header HOY.
- Igualar geometría con CHAT CON ARIS vía `AppSpacing`.
- Añadir microencabezado TAREAS con icono naranja.
- Mantener intacta la timeline de eventos (v0.48.27).

## 3. Decisiones de diseño

- La línea vertical de eventos queda como en v0.48.27 (`#C7DCFF` / `#416A98`).
- Header compacto: `minHeight` 38 px, padding vertical 5 px, chevron box 38 px (antes 44).
- Gap cabecera → contenido: 5 px (antes 7).
- TAREAS: fila icono + texto sin fondo; icono `#F59E0B` / `#FDBA74`; texto con estilo de sección (no naranja).
- El naranja se reserva solo para el icono de tareas.

## 4. Alcance

Incluye:

- `TodaySummaryCard`.
- `RecentConversationCard` (hereda geometría de `AppSpacing`).
- `AppSpacing`.
- Documentación.

No incluye:

- backend;
- servicios;
- modelos;
- GPT;
- navegación;
- lógica funcional;
- rediseño general;
- timeline / puntos / icono calendario.
