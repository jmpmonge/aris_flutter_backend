# v0.49.16 — Vista Notas: abrir nota existente como página inside, no expandir tarjeta

## 1. Contexto

La pantalla Notas necesitaba una decisión clara sobre qué ocurre al pulsar una nota existente. Se decide que la lista sea solo resumen y que el detalle se abra como página inside.

## 2. Objetivo

- Hacer que el tap en una nota abra una nota completa inside.
- Mantener las tarjetas como resumen compacto.
- Reutilizar el mismo lenguaje de lienzo limpio que en la creación manual.

## 3. Decisiones de diseño

- `ManualNoteCanvasSheet.openExisting` con `MaterialPageRoute` (sin modal ni bottom sheet).
- Mismo lienzo que nota nueva; flecha atrás y guardado con check.
- Preview en lista: máximo 2 líneas con elipsis.
- Edición por diálogo eliminada; el menú conserva solo eliminar.

## 4. Alcance

Incluye:
- `notes_screen.dart`
- `manual_note_canvas_sheet.dart`
- Este documento.

No incluye: backend, GPT, Home, Calendario, Tareas.
