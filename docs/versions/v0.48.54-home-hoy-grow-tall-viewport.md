# v0.48.54 — Home: HOY crece al alargar la pantalla

## Problema
En v0.48.53 el guard `_layoutTightenSteps` recortaba HOY en pantallas justas, pero no se liberaba al aumentar la altura del viewport: HOY seguía en mínimos aunque hubiera sitio.

## Cambios
- **Sync de altura del ListView**: si el viewport crece ≥10px, `_layoutTightenSteps = 0` y se recalculan conteos con `forListViewport` (evento → tarea → mail en ciclo).
- **Guard bidireccional**: si Aris queda cortada, `tighten++`; si hay ≥40px libres bajo Aris y había recorte, `tighten--` para probar más filas.
- Al **encoger** el viewport se vuelve a ejecutar el guard (aprieta si hace falta).
