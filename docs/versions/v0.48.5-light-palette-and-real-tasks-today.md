# v0.48.5 — Paleta clara documentada y tareas reales en TodaySummaryCard

## 1. Contexto

La Home ya se ha reorganizado: `SuggestionCard` es la primera tarjeta útil, la flecha de HOY enlaza con Calendario y HOY no incluye notas. En esta versión se documenta la paleta clara de referencia, se refuerza la separación visual calendario/tareas en HOY y se conectan las filas de tarea con la misma tarea en la pantalla de Tareas.

## 2. Objetivo

- Documentar la paleta clara de Aris y su uso semántico.
- Ajustar tokens existentes en `AppColors` de forma acotada (sin rediseñar toda la app).
- Reforzar el divisor entre bloque de calendario y bloque de tareas cuando **ambos** tienen contenido.
- Hacer las tareas de HOY pulsables y abrir `TasksScreen` con la fila expandible en la tarea elegida (`initialExpandedTaskId`).
- Alinear `getHomeHighlightTasks()` con reglas explícitas (sin tareas «próximas» con fecha futura real en HOY).

## 3. Paleta clara de Aris

Inspiración Clara adaptada a Aris; los hex de producto y la correspondencia con tokens del código:

| Uso en producto | Hex | Token / uso en código |
|-----------------|-----|------------------------|
| Fondo principal cálido | `#F7F3EC` | `AppColors.canvasLight` → `ColorScheme.surfaceContainerLowest` (lienzo) |
| Superficie / tarjetas | `#FFFDF8` | `AppColors.surfaceLight` → `ColorScheme.surface` |
| Azul marino identidad | `#102A56` | `AppColors.primaryDeep` → `ColorScheme.primary` |
| Azul marino profundo | `#071B3F` | `AppColors.primaryNavyDeep` → textos sobre contenedor primario |
| Texto principal | `#132B4F` | `AppColors.textPrimaryLight` → `ColorScheme.onSurface` |
| Texto secundario | `#6E7480` | `AppColors.textSecondaryLight` → `ColorScheme.onSurfaceVariant` |
| Violeta IA | `#7B6FF2` | `AppColors.secondaryViolet` → `ColorScheme.secondary` |
| Lavanda suave | `#D9D2FF` | *(No token dedicado; cercano a `violetContainer` / secundario)* |
| Azul calendario / eventos | `#2F7DF6` | `AppColors.calendarBlue` → punto de evento en HOY (modo claro) |
| Verde tareas | `#45B36B` | `AppColors.taskGreen` → icono de tarea pendiente en HOY |
| Coral / melocotón | `#FF8A84` / `#FFE3CF` | *(Pendiente extensión chips; no aplicado globalmente en v0.48.5)* |
| Línea divisoria | `#E4E1DA` | `AppColors.outlineLight` → bordes / divisor HOY calendario↔tareas |

**Semántica:** azul marino (identidad), crema/blanco roto (superficie), violeta (IA/acento), azul fuerte (eventos en HOY), verde (tareas), gris azulado (secundario), línea crema (separación).

## 4. TodaySummaryCard

- **Calendario y tareas:** siguen siendo datos de `Repositories.calendar.getHomeHighlightEvents()` y `Repositories.task.getHomeHighlightTasks()` (sin notas).
- **Divisor:** 1 px, margen vertical 9 px; en claro color cercano a `#E4E1DA`; **solo** si hay al menos un evento **y** al menos una tarea.
- **Estado vacío:** si no hay eventos ni tareas → «Sin eventos ni tareas para hoy.»; si solo faltan eventos → «Sin eventos para hoy.» + tareas sin divisor entre vacío y tareas.
- **Eventos:** punto de color `calendarBlue` en modo claro.
- **Tareas:** fila con `InkWell` mínimo 44 pt de alto útil; icono verde si pendiente; pulsación → callback → `TasksScreen(initialExpandedTaskId: id)` (misma tarea, detalle expandible que en la lista de Tareas).
- **Reglas de lista (repositorio):** HOY = tareas en buckets `today` + `noDate` según `TaskGroupedLists.partition` (incluye vencidas y hoy civil por `date_iso` / `date_text` estructurado); **excluye** bucket `upcoming` (fechas futuras reales). Sin servicios GPT ni interpretación de título libre. Si no hay candidatos y hay cache, hasta 3 tareas **no completadas** como respaldo.

## 5. Alcance

## 7. Cambios implementados

- Paleta clara alineada con la tabla anterior; añadidos `calendarBlue`, `taskGreen`; modo oscuro de `darkScheme` sin cambios sustantivos.
- `getHomeHighlightTasks`: fuente online = `today` + `noDate`, máximo 3; sin `upcoming`; offline = partición de mocks `getTodayTasks` + `getUpcomingTasks` con la misma regla; fallback a lista mock previa si queda vacío.
- HOY: divisor reforzado solo con eventos y tareas simultáneos; textos de vacío unificados según caso.
- Tap en tarea: navegación a ruta Material con `TasksScreen(initialExpandedTaskId: …)` y `CompactExpandableTaskTile(initiallyExpanded: true)` para ese id.
