# v0.49.5 — Calendario: sustituir CTA inferior por input fijo de Aris como en Home

## 1. Contexto

La parte baja de Calendario tenía duplicidad de CTA: bloque «Nada aquí…», botón central azul y navegación inferior. Eso generaba ruido y falta de coherencia con Home.

## 2. Objetivo

- Eliminar el bloque «Eventos creados por Aris» / «Nada aquí…».
- Quitar el FAB azul en la pestaña Calendario.
- Usar el mismo `HomeArisFixedInputBar` que en Home (parámetro `hintText` opcional).
- Reservar espacio inferior con `dockHeight` + `homeScrollBottomBreathing`.

## 3. Decisiones de diseño

- `Column` + `Expanded(ListView)` + input fijo (mismo patrón que Home).
- Placeholder Calendario: «Añade un evento con Aris…».
- FAB oculto en shell cuando `_tabIndex == 1` (Inicio y Calendario).
- Se mantiene la lista «Todos los eventos del servidor» si hay datos backend.

## 4. Alcance

Incluye:
- `calendar_screen.dart`
- `home_aris_reply_card.dart` (`hintText`)
- `app_navigation_shell.dart` (FAB)
- `calendar_body_views.dart` (quita `SizedBox` extra bajo rejilla pensado para FAB)

No incluye: backend, Home (solo param opcional con default), Día/Semana/Mes contenido, nav global.
