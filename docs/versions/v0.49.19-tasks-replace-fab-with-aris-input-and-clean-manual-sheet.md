# v0.49.19 — Vista Tareas: sustituir FAB por input fijo de Aris y limpiar ficha de nueva tarea

## 1. Contexto

La vista Tareas necesitaba alinearse con Calendario y Notas en la parte inferior, eliminando el FAB azul y adoptando el input fijo de Aris. También necesitaba una ficha manual de creación más limpia.

## 2. Objetivo

- Eliminar el FAB azul en Tareas.
- Añadir el input fijo inferior de Aris.
- Mantener el + arriba como creación manual.
- Refinar la ficha de «Nueva tarea».

## 3. Decisiones de diseño

- FAB oculto en pestaña Tareas (índice 3).
- `HomeArisFixedInputBar` con hint «Pide a Aris crear o buscar tareas…».
- Ficha manual: título sin subtítulo técnico, espaciados compactos, sin botón Cancelar duplicado (drag handle del sheet).

## 4. Alcance

Incluye:
- `tasks_screen.dart`
- `app_navigation_shell.dart`
- `_TaskFormBody` en `local_action_form_sheet.dart`
- Este documento.

No incluye: backend, lista/expansión de tareas, otras pantallas.
