# v0.49.17 — Vista Tareas: limpieza inicial y expansión de tarjeta al pulsar

## 1. Contexto

La pantalla Tareas necesitaba una primera limpieza de copy y una regla clara de interacción. Se decide mantener el check como gesto de completar y usar la expansión de tarjeta para mostrar detalle.

## 2. Objetivo

- Limpiar el texto superior de Tareas.
- Mantener el check redondo para completar.
- Hacer que el tap en la tarjeta expanda el detalle.
- Evitar pantalla inside y doble tap por ahora.

## 3. Decisiones de diseño

- `AppHeader` sin subtítulo provisional.
- Check con `CircleBorder`.
- Tap en el cuerpo de la tarjeta (InkWell) alterna expansión; el check no expande.

## 4. Alcance

Incluye:
- `tasks_screen.dart`
- `compact_expandable_task_tile.dart`
- Este documento.

No incluye: backend, GPT, Home, Calendario, Notas.
