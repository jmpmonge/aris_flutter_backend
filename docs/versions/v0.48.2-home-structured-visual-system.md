# v0.48.2 — Sistema visual compacto-premium de Home basado en Structured

## 1. Contexto

v0.48.0 inició el rediseño visual de Home.

v0.48.1 compactó el bloque superior.

v0.48.2 aplica un sistema visual coherente a la Home completa, tomando **Structured** como referente principal (no copia literal).

## 2. Objetivo

Unificar proporciones, tarjetas, navegación y tipografía de la Home para conseguir una interfaz **compacta-premium** y de productividad diaria.

## 3. Referente visual

Structured se usa como referencia por:

- navegación inferior clara;
- botón flotante de acción separado de la pestaña principal;
- tarjetas anchas y bajas;
- iconos sólidos y jerarquía tipográfica marcada;
- sensación premium sin exceso de aire vacío.

## 4. Sistema de medidas (Home)

| Token | Valor |
| --- | --- |
| Margen lateral global | **18 px** (`homePageMarginH`; mínimo denso 16) |
| Separación entre bloques | **12 px** (`homeSectionGap`; máx. principal 16) |
| Cabecera → Greeting | **14 px** (`homeHeaderToGreetingGap`) |
| Radio tarjetas | **22 px** (`homeCardRadius`) |
| Radio interno / listas | **18 px** (`homeCardRadiusInner`) |
| Padding tarjetas | **14 px** (`homeCardPadding`; compacto 12) |
| Header marca / subtítulo | **32 / 14 px** |
| GreetingCard altura | **96 px** (máx. guía 100) |
| SuggestionCard altura objetivo | **82 px** (máx. 88) |
| HOY / filas | título **17**; filas **~14.5**; iconos fila **21** |
| Altura lista “Reciente” | **220 px** (área scroll interno) |
| Input “Escribe a Aris…” | fila **52 px**; radio **22**; placeholder **14.5**; mic **48** / icono **24** |
| Navegación inferior (cápsula) | **76 px** alto; radio **34**; iconos **26**; etiqueta **11.5** |
| FAB asistente (no Inicio) | **64 px**; icono **34** |

Colores: se mantiene el **ColorScheme** existente (primario marino, secundario violeta salvo); el FAB sigue usando **primary** por identidad Aris.

## 5. Alcance

Incluye:

- `ArisHeader`, `GreetingCard`, `SuggestionCard`, `TodaySummaryCard`, `LatestArisActionSection`, `RecentConversationCard`.
- `ChatInputBar` y envoltorio de **navegación tipo cápsula** en `AppNavigationShell` + `AppBottomNavigation`.
- `AppFloatingActionButton` (tamaño/icono).
- `AppSpacing`, `AppTypography`, `AppTheme` (NavigationBar + FAB theme).

No incluye: backend, servicios, modelos, endpoints, GPT, rutas nuevas ni cambios funcionales de navegación.

## 6. Cambios implementados

- Escala tipográfica global alineada con la tabla del spec (`AppTypography`).
- Márgenes Home a **18 px** y separaciones verticales **12 / 14 px** según bloque.
- Tarjetas con radio **22**, sombras mínimas, bordes suaves.
- **NavigationBar** en cápsula con margen horizontal 18 px, altura 76 px, indicador suave.
- Barra de chat fija con altura de fila 52 px y micrófono 48 px.
- FAB 64 px e icono 34 px vía tema + widget.
