# v0.49.20 — Vista Tareas: editor más compacto, iconos activables y entrada desde abajo a pantalla completa

## 1. Contexto

La entrada manual de tarea seguía viéndose demasiado formularia y pesada. Se decide transformarla en un editor más ligero, que entra desde abajo como vista completa y usa metadatos activables por icono.

## 2. Objetivo

- Hacer que el editor de tarea suba desde abajo y ocupe la pantalla completa.
- Compactar mucho más el layout.
- Representar fecha, hora y prioridad con iconos activables.
- Eliminar la sensación de dropdowns o formularios persistentes en la fila de metadatos.

## 3. Decisiones de diseño

- `ManualTaskEditorPage` con `PageRouteBuilder` y slide desde abajo.
- Título y cuerpo sin labels de formulario.
- Fecha/hora: iconos + valor compacto; pickers al pulsar.
- Prioridad: icono bandera toggle (high/normal), sin segmented control.
- Un solo CTA «Crear tarea» abajo; cerrar arriba.

## 4. Alcance

Incluye:
- `manual_task_editor_page.dart` (nuevo)
- `local_action_form_sheet.dart` (delegación)
- Este documento.

No incluye: backend, lista de tareas, input de Aris.
