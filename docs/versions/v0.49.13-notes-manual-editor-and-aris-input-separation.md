# v0.49.13 — Vista Notas: editor manual desde «Nueva nota» y input inferior reservado para Aris

## 1. Contexto

La pantalla Notas necesitaba separar claramente la creación manual de notas de la interacción conversacional con Aris.

## 2. Objetivo

- Mantener «Nueva nota» como vía manual.
- Hacer que abra un editor vacío con título y contenido.
- Reservar el input inferior solo para Aris.
- Reducir ambigüedad de uso en la pantalla.

## 3. Decisiones de diseño

- `LocalActionFormSheet.showManualNoteForm`: sheet con título y contenido separados (sin categoría ni copy «con Aris»).
- `HomeArisFixedInputBar` en Notas con hint «Pide una nota a Aris…» y envío vía `Repositories.assistant`.
- FAB del shell oculto en pestaña Notas (índice 2), como Inicio y Calendario.

## 4. Alcance

Incluye:
- `notes_screen.dart`
- `local_action_form_sheet.dart` (formulario manual)
- `app_navigation_shell.dart` (FAB)
- Este documento.

No incluye: backend, GPT, Home, Calendario, Tareas, rediseño global.
