# v0.49.12 — Vista Notas: limpieza inicial de copy técnico y mensajes provisionales

## 1. Contexto

La pantalla Notas seguía mostrando copy técnico y mensajes demasiado provisionales, lo que la alejaba del nivel visual ya alcanzado en Calendario.

## 2. Objetivo

- Eliminar texto técnico del encabezado.
- Limpiar el mensaje del bloque «Notas creadas por Aris».
- Mantener el resto de la pantalla sin rediseño.

## 3. Decisiones de diseño

- `AppHeader` sin subtítulo técnico.
- Estado vacío: «Aún no hay notas de Aris.» (sustituye el mensaje largo con instrucciones de demo).
- Sin cambios en buscador, chips, recientes ni FAB.

## 4. Alcance

Incluye:
- `notes_screen.dart`
- Este documento.

No incluye: backend, Home, Calendario, Tareas, rediseño global.

cd aris_flutter_v0.22
