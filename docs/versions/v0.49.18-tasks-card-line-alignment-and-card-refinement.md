# v0.49.18 — Vista Tareas: alinear línea principal con check y refinar tarjeta expandible

## 1. Contexto

La vista Tareas ya tenía una interacción correcta, pero la línea principal de cada tarea y la tarjeta expandible todavía necesitaban una pasada de precisión visual.

## 2. Objetivo

- Alinear correctamente check y título.
- Refinar la tarjeta en estado colapsado.
- Mejorar la presentación del detalle expandido.
- Mantener intacta la lógica de interacción.

## 3. Decisiones de diseño

- Check en ranura 22×22 centrada; separación 10 px al texto.
- Tarjeta plana: elevación 0, borde sutil, radio 14.
- Detalle expandido bajo divisor, alineado con columna de texto.
- `AnimatedSize` 220 ms `easeOutCubic`.

## 4. Alcance

Incluye:
- `compact_expandable_task_tile.dart`
- espaciado entre tarjetas en `tasks_screen.dart`
- Este documento.

No incluye: backend, modal de nueva tarea, otras pantallas.

cd aris_flutter_v0.22
