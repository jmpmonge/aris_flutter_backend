# v0.48.8 — Ajuste fino de timeline, tareas, cabecera de sugerencia y marca Aris

## 1. Contexto

La Home ya está estructurada. Esta versión aplica ajustes finos sin rediseño general.

## 2. Objetivo

- Hacer continua la línea vertical del calendario en la columna timeline.
- Limitar tareas visibles a un máximo de dos y mostrar “+ X tareas más” si aplica.
- Representar estados de tarea (pendiente, en curso si el modelo lo permite, completada).
- Integrar la bombilla en la cabecera junto a “SUGERENCIA”.
- Mejorar visualmente la marca “aris” sin fuentes externas.

## 3. Alcance

**Incluye:**

- `today_summary_card.dart`
- `suggestion_card.dart`
- `aris_header.dart`
- este documento

**No incluye:**

- backend, servicios, modelos, GPT
- navegación inferior, input inferior, Chat con Aris, HomeScreen
- rediseño general ni `AppTypography` global

## 4. Decisiones de diseño

- **Timeline:** una sola línea vertical en un `Stack` detrás de la `Table` de eventos; los puntos opacos dibujan encima y ocultan el tramo bajo cada punto (continuidad visual sin segmentos por fila).
- **Tareas en Home:** como mucho dos filas; el resto se resume con “+ X tareas más”.
- **Estados:** `completed` → check verde; pendiente → `radio_button_unchecked_rounded` gris; en curso solo si `priority` coincide con valores alineados al backend (`in_progress`, `doing`, `active`, etc.) → icono `pending_rounded` y color calendario; si no hay prioridad reconocible, todo lo no completado es pendiente.
- **SuggestionCard:** fila `[icono bombilla] + SUGERENCIA` en verde marca; mensaje debajo sin cambiar datos.
- **Marca “aris”:** peso 700, interletrado -0.78, altura de línea ~1.08; fuente decorativa = pendiente futura.

## 6. Cambios implementados

- Eventos: bloque único `Stack` + `Table`; línea `Positioned` de arriba a abajo si hay ≥ 2 eventos; eliminación de segmentos/gaps entre filas para la línea.
- Tareas: slice de dos ítems; texto “+ N tareas más”; iconos según `_homeTaskKind`.
- Sugerencia: cabecera en `Row` con bombilla y etiqueta verde.
- Cabecera: refuerzo tipográfico del texto “aris”.
