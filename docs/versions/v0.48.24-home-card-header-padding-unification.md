# v0.48.24 — Unificación de padding y altura en cabeceras de tarjetas Home

## 1. Contexto

Las cabeceras de **SUGERENCIA**, **HOY** y **CHAT CON ARIS** tenían padding, gap entre icono y título, radio del área interactiva y tratamiento del chevron distintos. **CHAT CON ARIS** se tomó como referencia visual y se extrajo un único sistema de medidas compartido.

## 2. Objetivo

Unificar padding, altura mínima del cajetín, radio del hover/pressed, tamaño del icono, separación icono–título y caja 44×44 del chevron (cuando aplica) para que las tres cabeceras se perciban como la misma familia de componentes.

## 3. Decisiones de diseño

- Patrón centralizado en [`AppSpacing`](aris_flutter_v0.22/lib/theme/app_spacing.dart): `homeCardHeaderInkPaddingH` (10), `homeCardHeaderInkPaddingV` (7), `homeCardHeaderInkBorderRadius` (14), `homeCardHeaderIconSize` (22), `homeCardHeaderIconTitleGap` (8), `homeCardHeaderMinHeight` (44), `homeCardHeaderChevronSize` (26), `homeCardHeaderChevronBox` (44).
- Valores finos alineados con el rango recomendado en spec (padding H 10, V 7, radio 14, icono 22, gap 8).
- **HOY** y **CHAT CON ARIS** comparten forma del `InkWell`; los colores de overlay se mantienen distintos (azul vs lavanda).
- **SUGERENCIA** no tiene overlay en cabecera; se aplica el mismo inset izquierdo (`InkPaddingH`) y la misma grilla icono + gap para alinear con las otras tarjetas. El cuerpo del texto se desplaza con la suma `inset + icono + gap` (40 px desde el borde interno de contenido).

## 4. Alcance

**Incluye**

- `TodaySummaryCard` — cabecera HOY (variante con `InkWell` y variante estática sin callback).
- `RecentConversationCard` — `_ChatWithArisHeader`.
- `SuggestionCard` — fila de icono + «SUGERENCIA» y tabulado del mensaje.
- `AppSpacing` — tokens `homeCardHeader*`.
- Esta nota.

**No incluye**

- Backend, servicios, modelos, GPT, navegación.
- Lógica de datos de calendario, tareas o chat.
- Tipografía global ni textos.

## 6. Cambios implementados

- Nuevas constantes `homeCardHeader*` en `AppSpacing`.
- **CHAT CON ARIS**: sustitución de constantes locales por `AppSpacing`; icono 22 (antes 24); gap 8 (antes 10); padding 10/7 y radio 14 (antes 9/7 y 13); chevron centrado en caja 44×44.
- **HOY**: mismos tokens; icono 22; chevron dentro de `SizedBox` 44×44 centrado con tamaño 26; misma estructura en modo no interactivo con el mismo padding para no desalinear si falta callback.
- **SUGERENCIA**: `Padding` izquierdo de cabecera = `homeCardHeaderInkPaddingH`; icono y gap unificados; indent del cuerpo = 40 px desde el inicio del área de contenido interna de la tarjeta (tras el padding 14 del card).
