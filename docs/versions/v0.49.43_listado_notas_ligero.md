# v0.49.43 — Listado de notas ligero y limpio

## 1. Objetivo

Refinar la pantalla de listado de Notas para que sea más concisa, legible e intuitiva, sin rediseñar la estructura ni añadir buscador superior. Equilibrio entre Apple Notes y identidad Aris oscura.

## 2. Qué se mantiene

- Título «Notas» y botón **+** (nueva nota amplia).
- Sección **Recientes**.
- Tarjetas de notas (no lista plana).
- Input inferior: «Pide a Aris crear o buscar notas…» encima de la botonera.
- Botonera: Inicio / Calendario / Tareas / **Notas** / Perfil (sin Mail).
- Sin buscador arriba.
- Sin cambios en nota amplia, checklist, tablas, calendario, tareas ni perfil.

## 3. Cambios visuales

### Tarjetas (`NoteListCard`)

- Fondo `#111A25` con ligera transparencia (menos protagonista).
- Borde `#243244` fino y sutil (~35 % opacidad), sin sombra fuerte.
- Radio 14 px; padding vertical reducido (10 px).
- Título en **semibold**; preview en `bodySmall` gris secundario, máx. 2 líneas.
- Separación entre tarjetas: 8 px (`AppSpacing.xs`).

### Sección «Recientes»

- Color azul Aris (`#5EA8FF`).
- Tamaño 12 px, peso semibold, espaciado superior equilibrado.

### Chincheta (notas fijadas)

- Icono `push_pin` 15 px, celeste Aris al 60 % opacidad.
- Arriba a la derecha, alineado con el título.
- Visible si `NoteModel.pinned == true`.
- **Futuro**: persistencia desde backend / editor amplio; el campo `pinned` ya está en el modelo (`pinned`, `isPinned`, `fixed` en JSON).

### Input Aris

- Sin cambios de copy ni posición.
- Padding inferior de lista aumentado ligeramente para no solapar tarjetas con el dock.

## 4. Decisiones

| Decisión | Motivo |
|----------|--------|
| No buscador superior | Alcance v0.49.43; Aris abajo cubre crear/buscar |
| Mantener tarjetas | Legibilidad Aris; solo aligerar peso visual |
| No sección «Fijadas» | Solo indicador discreto en tarjeta |
| `pinned` opcional en modelo | Soporte visual listo sin lógica de backend compleja |


### Manual

1. Abre pestaña Notas: sin buscador arriba.
2. «Recientes» en azul Aris, tamaño pequeño.
3. Tarjetas más ligeras (borde fino, menos altura).
4. Con `pinned: true` en una nota (mock/JSON), chincheta discreta visible.
5. Input Aris abajo; no solapa tarjetas al scroll.
6. Botonera con Perfil; Notas activa.
7. Tap en tarjeta → nota amplia sin regresiones.
