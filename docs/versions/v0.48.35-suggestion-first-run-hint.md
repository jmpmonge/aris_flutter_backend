# v0.48.35 — Pista visual inicial para tarjeta SUGERENCIA

## 1. Contexto

La tarjeta SUGERENCIA es descartable al pulsar, pero no era obvio en el primer uso.

## 2. Objetivo

- Pista única y sutil: «Toca para ocultar».
- Pulso suave del icono (1.0 → 1.08 → 1.0).
- Sin modal, snackbar ni tutorial largo.

## 3. Comportamiento

| Fase | Duración |
|------|----------|
| Espera inicial | 700 ms |
| Pulso icono | 800 ms |
| Texto visible | 2500 ms |
| Fade texto | 280 ms |

Persistencia: `SharedPreferences`, clave `aris_home_suggestion_hint_seen`.

## 4. Archivos

- `lib/core/prefs/home_suggestion_hint_prefs.dart`
- `lib/shared/widgets/suggestion_card.dart` (`SuggestionCardWithFirstRunHint`, `iconScale`)
- `lib/features/home/presentation/home_screen.dart`
- `docs/versions/v0.48.35-suggestion-first-run-hint.md`
