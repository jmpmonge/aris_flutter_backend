# v0.49.6 — Vista Semana: preparar icono + palabra para eventos con soporte backend futuro y fallback simple

## 1. Contexto

La vista Semana ya funciona bien estructuralmente, pero el bloque visual del evento semanal todavía puede mejorar. Se quiere dejar preparado para consumir en el futuro `icono_semana` y `texto_semana` desde backend, sin implementar aún backend ni clasificación compleja en frontend.

## 2. Objetivo

- Preparar el render del evento semanal para soporte backend futuro.
- Usar `icono_semana` y `texto_semana` si existen.
- Definir un fallback simple si no existen.
- Mejorar el envoltorio visual del evento semanal.

## 3. Decisiones de diseño

- `EventModel.weekIconKey` / `weekLabelText` opcionales; parseo en `BackendEventMapper` y `fromJson`.
- `CalendarWeekEventBadgeResolver`: mapa pequeño de claves backend → `IconData` (no clasificación por título).
- Fallback: `Icons.event_rounded` + primera palabra del título (máx. 9 caracteres).
- Bloque: `Row` icono 13 px + etiqueta una línea, padding 4×3, sin menú en celda.

## 4. Alcance

Incluye:
- `calendar_week_event_badge.dart`
- `calendar_body_views.dart` (`_weekEventBlock`)
- `event_model.dart`, `backend_event_mapper.dart` (solo lectura de campos opcionales)

No incluye: backend servidor, GPT, Home, Día, Mes, rediseño de rejilla.
