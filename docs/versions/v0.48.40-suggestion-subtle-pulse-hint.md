# v0.48.40 — Pista visual ampliada para SUGERENCIA sin texto

## 1. Contexto

Se descarta el uso de texto como «Ocultar sugerencia» y de iconos tipo check. Se mantiene una pista visual circular más clara y suave.

## 2. Objetivo

- Sustituir texto por un pulso visual.
- Hacer el pulso más grande, lento y visible.
- Mantenerlo en la zona superior derecha de la tarjeta.
- Mostrarlo solo la primera vez.
- No alterar el layout ni la ocultación de SUGERENCIA.

## 3. Decisiones de diseño

- La pista es visual, no verbal.
- No se usa check para evitar confusión con tareas.
- El pulso actúa como affordance sutil.
- **Dos pulsos** lentos de **1500 ms** cada uno (≈ **3 s** de animación + **3000 ms** de delay inicial; ≈ **6 s** hasta fin de pista).
- Escala **1.0 → 1.30 → 1.0**; halo máximo **36 px**.
- Curva **`Curves.easeInOutCubic`**.
- Claro: `#2FAE68`, opacidad máx. **0.20**.
- Oscuro: `#8FE6B2`, opacidad máx. **0.22**.

## 4. Alcance

Incluye:

- `lib/shared/widgets/suggestion_card.dart`
- Documentación

No incluye:

- TodaySummaryCard, backend, servicios, modelos, GPT, calendario, tareas, timeline, rediseño general, fecha superior, animación de ocultación de SUGERENCIA.
