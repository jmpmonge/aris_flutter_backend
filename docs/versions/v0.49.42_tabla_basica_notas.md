# v0.49.42 — Tabla básica en notas

## Objetivo

Insertar tablas simples (2×3) en la nota amplia desde el icono de tabla de la toolbar.

## Implementación

- Formato serializado: bloques `[TABLE cols=2]` … `[/TABLE]` con celdas separadas por `|`.
- Modelo `NoteTableBlock` + editor `NoteTableBlockEditor`.
- Inserción en posición del cursor dentro de un bloque de prosa, o al final si no hay foco.
- «Escribir debajo» crea/enfoca texto normal bajo la tabla.
- Bloques ordenados: prosa y tablas intercaladas.
- Añadir fila opcional por tabla.
