# v0.48.20 — Ajuste de hover en texto de eventos y tareas

## 1. Contexto

Tras v0.48.19, el hover de eventos envolvía hora, punto y timeline. El hover de tareas quedaba pegado al texto (poco padding, radio pequeño).

## 2. Objetivo

- Limitar hover/pressed de **eventos** al bloque **título + subtítulo** (no hora, punto ni línea vertical).
- Envolver el texto de **tareas** en una cápsula con padding y radio claros; icono de estado fuera del área de expansión.
- Mantener filas compactas (`_taskRowGap` 3 px; altura mínima fila 30 px).
- Colores coherentes: **eventos y texto de tareas** usan la misma cápsula azul (`_calendarEventRowOverlayColor`); el panel expandido de tarea conserva ámbar/amarillo.

## 3. Decisiones de diseño

- **Eventos:** `InkWell` solo en `Expanded` con columna de textos; `Row` exterior solo hora + punto + gap + bloque textual. Línea timeline: `axisLeft = tw + (cw - lineW) / 2`; centro vertical del punto sin padding de fila completa.
- **Eventos y bloque textual de tareas:** padding **9** × **6** px, radio **12** px; overlay **#EAF3FF** / **#DDEBFF** (claro) y **#10243F** / **#1A2F4A** (oscuro) vía `_calendarEventRowOverlayColor`.
- **Tareas:** icono de completar a la izquierda con el mismo overlay azul al pulsar. **Expandido** de tarea sin cambios (ámbar).
