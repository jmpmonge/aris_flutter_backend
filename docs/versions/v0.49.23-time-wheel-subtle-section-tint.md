# v0.49.23 — Ruleta de hora: tinte sutil con color de sección

## 1. Contexto

La ruleta de hora ya estaba resuelta funcionalmente, pero faltaba un remate visual fino para que la selección activa reflejara mejor el color de cada sección.

## 2. Objetivo

- Añadir tinte azul sutil en la selección activa de Calendario.
- Añadir tinte naranja/coral sutil en la selección activa de Tareas.
- No tocar nada más del picker ni del editor.

## 3. Decisiones de diseño

- Franja central fija (`IgnorePointer`) sobre `CupertinoDatePicker`: relleno al 7 % del acento, borde al 14 %.
- Sin sombra fuerte ni fondo completo coloreado.
- Calendario y Tareas siguen pasando su `accent` al mismo widget compartido.

## 4. Alcance

Incluye:
- `section_accent_time_wheel_picker.dart`
- este documento.

No incluye: backend, copy, layout de editores, apertura del picker.
