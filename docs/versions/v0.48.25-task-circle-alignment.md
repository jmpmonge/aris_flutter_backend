# v0.48.25 — Alineación del círculo de tareas en TodaySummaryCard

## 1. Contexto

Alinear **solo** el bloque tarea: círculo/check + frase como una unidad. No forzar la columna de tareas a la malla de la cabecera HOY ni a la columna de eventos del timeline si eso rompe la relación icono–texto.

## 2. Objetivo

- **12 px** entre círculo y bloque textual (`SizedBox` entre icono y `Expanded`).
- Primera fila **`Row(crossAxisAlignment: center)`** entre icono y título: centra el círculo (glifo 22 px en columna 22×44) con el **centro vertical** del bloque InkWell del título (no `start` + `paddingTop`, para no pegar el icono a la base del texto).
- Panel expandido **debajo** del `Row`, con **`Padding(left: 22+12, top: 3)`** para alinear el contenido con el título; el icono **no** participa en la altura del panel.
- Sin padding horizontal extra interno en el texto del título.
- **`_taskRowLeftInset` = 12 px** en el `Padding` exterior.

## 3. Cambios (`_TaskRow`)

- **Archivo:** `aris_flutter_v0.22/lib/shared/widgets/today_summary_card.dart`.

Estructura:

```text
Padding(only left: 12) → Column → [
  Row(crossAxisAlignment: center) → [ icono 22×44 + InkWell, SizedBox(12), Expanded(título+meta) ],
  si expandido: Padding(left: 22+12, top: 3) → panel,
]
```

- **Fila título + icono:** `CrossAxisAlignment.center` para alinear en el **eje vertical** el centro del círculo (22 px centrado en la columna) con el **centro** del bloque InkWell del título (misma franja óptica que la primera línea con padding simétrico vertical).
- El panel expandido va **fuera** de ese `Row`, con **`Padding(left: icono + gap)`** para que la descripción siga alineada con el título; el círculo **no** se re-centra respecto al panel.
- **`_iconTextGap` = 12 px**; sin `paddingTop` manual en el icono.
