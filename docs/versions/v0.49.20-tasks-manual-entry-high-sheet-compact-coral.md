# v0.49.20 — Vista Tareas: entrada manual más compacta, sheet alto y acento coral/naranja

## 1. Contexto

La entrada manual de tarea seguía viéndose demasiado formularia y pesada. Se decide llevarla a un sheet alto (~68 %), más compacto y más cercano a una nota enriquecida, con acento coral funcional.

## 2. Objetivo

- Hacer que el editor entre desde abajo sin ocupar toda la pantalla.
- Compactar mucho más la interfaz.
- Hacer ligera la fila de fecha, hora y prioridad.
- Usar coral/naranja solo como acento funcional.

## 3. Decisiones de diseño

- `showModalBottomSheet` con altura ~68 % y drag handle.
- Metadatos en chips redondos compactos; prioridad solo icono.
- Notas: 3–6 líneas, sin `Expanded` vacío.
- `TaskManualEditorAccent` (#F4A261 / #E07A3A) para iconos activos y CTA.

## 4. Alcance

Incluye:
- `manual_task_editor_page.dart`
- Este documento.

No incluye: backend, lista de tareas, input de Aris.
