# v0.49.22 — Calendario: creación manual alineada con Tareas, acento azul y hora compacta

## 1. Contexto

La revisión transversal detectó que la creación manual de Calendario seguía desalineada respecto a Tareas y mantenía un lenguaje menos claro. Además, se define que el acento funcional de la sección debe ser azul.

## 2. Objetivo

- Mantener + como creación manual.
- Quitar tono Aris/técnico.
- Alinear el editor manual de Calendario con Tareas.
- Usar azul como acento activo de metadatos.
- Refinar la hora con una solución más compacta.

## 3. Decisiones de diseño

- + superior = manual.
- input inferior = Aris.
- Sheet alto desde abajo (~68 %).
- Lenguaje visual común con Tareas.
- Azul funcional: `AppColors.calendarBlue` / `calendarBlueDark` vía `EventManualEditorAccent`.
- Hora: icono `access_time` 15 px + campo inline `hh:mm` (sin `showTimePicker` por defecto).

## 4. Alcance

Incluye:
- `manual_event_editor_page.dart`
- documentación.

No incluye: backend, input inferior, vistas del calendario, Tareas.
