# v0.49.8 — Vista Semana: leer icono_semana desde datos mock existentes

## 1. Contexto

La vista Semana ya funciona, pero aún usa icono genérico en todos los eventos. Se quiere aprovechar el mock actual para aportar `icono_semana` sin crear sistemas nuevos.

## 2. Objetivo

- Localizar el mock existente.
- Añadir `icono_semana` a los eventos de prueba.
- Hacer que la vista Semana use ese campo si existe.
- Mantener fallback al icono genérico si no existe.

## 3. Decisiones de diseño

- Mock: `lib/core/mock/mock_events.dart` (`weekIconKey` en cliente = `icono_semana` futuro).
- Claves mock: `coffee`, `sync`, `meal`, `send`, `gym`, `shopping`.
- Resolver: mapa ampliado; si solo hay icono sin `texto_semana`, etiqueta sigue siendo fallback del título (sin cambiar burbuja).

## 4. Alcance

Incluye:
- `mock_events.dart`
- `calendar_week_event_badge.dart` (mapa + lectura `weekIconKey`)

No incluye: backend, burbuja visual, rejilla, archivos nuevos de presets.
