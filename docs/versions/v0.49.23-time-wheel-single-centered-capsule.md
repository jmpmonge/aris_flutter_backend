# v0.49.23 — Picker de hora: selección más fina con una sola cápsula central

## 1. Contexto

La ruleta de hora ya estaba bien resuelta funcionalmente, pero la selección activa seguía viéndose demasiado compuesta por la combinación de banda larga y cápsula interior.

## 2. Objetivo

- Eliminar la banda larga.
- Dejar una sola cápsula central.
- Mantener el color de sección de forma sutil.
- Igualar la geometría entre Calendario y Tareas.

## 3. Decisiones de diseño

- `selectionOverlayBuilder` devuelve `null` → sin overlay nativo por columna.
- Una cápsula central: 128×28 px, radio 14, relleno al 9 % del acento.
- Sin borde ni segunda capa.

## 4. Alcance

Incluye: `section_accent_time_wheel_picker.dart` y este documento.

No incluye: layout de editores, lógica de guardado, backend.
