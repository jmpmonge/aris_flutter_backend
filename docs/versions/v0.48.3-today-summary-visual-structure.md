# v0.48.3 — Reestructuración visual de TodaySummaryCard y etiquetas de sección

## 1. Contexto

Tras el mapa visual de Home, se detectó que `TodaySummaryCard` mezclaba eventos, tareas y notas sin delimitación suficiente. También se detectó que las etiquetas HOY y RECIENTE tenían una presencia excesiva frente a SUGERENCIA.

## 2. Objetivo

Reestructurar visualmente `TodaySummaryCard` y unificar las etiquetas de sección con el estilo compacto de SUGERENCIA (referencia: `fontSize` 11.5, `fontWeight` 700, `letterSpacing` 0.7, `height` 1.0, `colorScheme.secondary`), copiado localmente en cada widget permitido sin refactor global.

## 3. Alcance

Incluye:

- `TodaySummaryCard`.
- Etiqueta HOY (cabecera con icono de calendario y chevron discreto).
- Etiqueta RECIENTE en `RecentConversationCard`.
- Separadores internos entre grupos (eventos / tareas / notas) cuando hay más de un tipo de contenido.
- Estructura visual de filas para eventos (hora, punto, título, subtítulo), tareas (círculo, título, metadatos) y notas (icono, línea compacta).

No incluye:

- `GreetingCard`.
- `SuggestionCard` (salvo como referencia de criterios copiados en código local).
- Home completa.
- `AppTypography` global.
- Navegación inferior ni barra de input.
- Backend, servicios, modelos, GPT ni rutas.

## 4. Decisiones de diseño

- HOY y RECIENTE pasan a ser etiquetas pequeñas de la misma familia que SUGERENCIA.
- Eventos, tareas y notas se agrupan visualmente; entre grupos con contenido se inserta un divisor fino (`outlineVariant` con opacidad ~0.21) y margen vertical ~9 px.
- No se usan títulos grandes internos tipo EVENTOS / TAREAS / NOTAS.
- La lógica de obtención de datos no cambia: se usan los mismos `EventModel`, `TaskModel` y `NoteModel` recibidos por el widget.
- Para eventos, la hora mostrada usa `timeText` del modelo si viene relleno; en caso contrario `timeHm` derivado de `start`. El subtítulo prioriza `detail`, luego `description`, luego `location` si aplica.

## 6. Cambios implementados

- `TodaySummaryCard`: cabecera HOY con icono `calendar_today_outlined`, tipografía de etiqueta compacta, chevron derecho en color secundario atenuado; filas de evento con columna de hora (~44 px), punto circular (~7.5 px), título y subtítulo; filas de tarea con `circle_outlined` y metadatos `dateText`/`timeText` a la derecha si existen; filas de nota con `sticky_note_2_outlined` y `homePreviewLine` de `NoteModel`; separadores entre bloques cuando hay más de un tipo con ítems.
- `RecentConversationCard`: etiqueta RECIENTE con los mismos parámetros de etiqueta compacta; borde de tarjeta alineado a alpha 0.18 como en otras tarjetas Home.
