# v0.48.23 — Tipografía geométrica redondeada para marca Aris

## 1. Contexto

Se sustituye la dirección serif anterior (Fraunces) por una tipografía sans geométrica redondeada para acercar la marca textual **«aris»** a la referencia visual: trazo grueso, formas suaves, aspecto tecnológico y amable.

## 2. Decisión tipográfica

La fuente objetivo para la marca textual «aris» es **Nunito Sans ExtraBold** (`FontWeight.w800`), cargada mediante el paquete **`google_fonts`** ya presente en el proyecto.

## 3. Motivo

Nunito Sans ofrece una estética:

- redondeada;
- amable;
- tecnológica;
- limpia;
- adecuada para una app de asistente personal.

## 4. Alcance

**Incluye**

- `ArisHeader` (`aris_flutter_v0.22/lib/features/home/presentation/widgets/aris_header.dart`).
- Marca textual «aris» (estilo del `Text`).
- Esta nota de versión.

**No incluye**

- `AppTypography` global;
- otros títulos de pantallas;
- `TodaySummaryCard`, `SuggestionCard`, chat u otras tarjetas Home;
- navegación;
- backend, servicios, modelos.

## 5. Cambios implementados

- `GoogleFonts.fraunces` sustituido por `GoogleFonts.nunitoSans`.
- Parámetros de estilo: `fontSize: 34`, `fontWeight: w800`, `letterSpacing: -1.1`, `height: 1.0`.
- Color modo claro: `#071B3F` (`Color(0xFF071B3F)`).
- Color modo oscuro: `#DCE8FF` (`Color(0xFFDCE8FF)`), manteniendo el contraste previo.
- Alineación: se conserva ` _contentPaddingLeft = 30` y el resto del layout (avatar «J», subtítulo).

## 6. Pendientes

- Unificar en otra versión los títulos de Calendario, Notas, Tareas y Perfil con la misma línea de marca si procede.

**No aplica en esta versión:** «Pendiente: añadir Nunito Sans ExtraBold como fuente de marca» — la fuente se aplica vía `google_fonts` sin asset local.
