# v0.49.22 — Calendario: creación manual alineada con Tareas y sin lenguaje de Aris

## 1. Contexto

La revisión transversal detectó que la creación manual de Calendario no estaba todavía alineada con la entrada manual refinada de Tareas y mantenía un tono visual/copy menos claro.

## 2. Objetivo

- Quitar lenguaje de Aris o técnico del editor manual.
- Mantener el + como creación manual.
- Alinear el editor manual de Calendario con el formato refinado de Tareas.
- Mantener el input inferior como canal de Aris.

## 3. Decisiones de diseño

- `ManualEventEditorPage`: sheet alto ~68 %, misma estructura que `ManualTaskEditorPage`.
- Título + chips fecha/hora/ubicación + notas en superficies redondeadas.
- Naranja solo en metadatos activos (reutiliza `TaskManualEditorAccent`).
- CTA «Crear evento» con color primary del tema.
- Sin copy «con Aris» ni `FormSectionTitle`.

## 4. Alcance

Incluye:
- `manual_event_editor_page.dart` (nuevo)
- `local_action_form_sheet.dart` (delegación)
- `calendar_screen.dart` sin cambios (sigue `showEventForm`)
- Este documento.

No incluye: backend, input inferior, vistas del calendario.
