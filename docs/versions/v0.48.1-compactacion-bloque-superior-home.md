# v0.48.1 — Compactación profesional del bloque superior de Home

## 1. Contexto

La versión funcional cerrada reciente es **v0.47.39** (borrado manual de notas y tareas). La fase visual comenzó con **v0.48.0** (inicio del rediseño de Home). Esta iteración **v0.48.1** reduce y proporciona el **bloque superior** (cabecera + primera tarjeta de saludo) a una escala de **app de uso diario**, no portada ni maqueta promocional.

## 2. Objetivo

Compactar profesionalmente solo:

- **`ArisHeader`** (marca «aris» + «Tu asistente personal»).
- **`GreetingCard`** (saludo + dos líneas secundarias breves + decoración derecha).
- **Separación** cabecera ↔ tarjeta.

Mantener estética **cálida y premium** con ocupación vertical total del bloque en torno a **~160–175 px** (referencia de diseño).

## 3. Alcance

### Incluye

- Ajuste de tipografía, márgenes, altura fija de tarjeta, sombra mínima, zona decorativa derecha (~88 px).
- Texto secundario fijado en **dos líneas cortas** definidas en UI (sin cambiar servicios ni modelos; ya no se usa `getHomeSummaryLine()` en esta tarjeta para evitar textos largos tipo “12 tareas…”).

### No incluye

- Rediseño del resto de Home, navegación, voz, sugerencias, “Hoy”, backend, servicios, modelos, GPT ni lógica de dominio.

## 4. Resolución profesional de diseño

La parte superior debe leerse como **cabecera compacta**: la marca existe pero no domina; la tarjeta comunica contexto en **poco espacio**, sin aspecto banner.

**Medidas objetivo aplicadas (reales):**

| Elemento | Valor |
|----------|--------|
| Margen lateral cabecera / tarjeta | **23 px** (rango 22–24) |
| Margen superior cabecera (tras SafeArea) | **16 px** |
| «aris» | **32 px**, w700, `#132B4F` |
| Subtítulo | **13 px**, `#6E7480`, separación **3 px** |
| Botón asistente | **36×36** px aprox., compacto (no 48 px de alto visual) |
| Hueco cabecera → tarjeta | **17 px** (rango 16–18) |
| Altura tarjeta | **92 px** (objetivo 90–94, máx. 96) |
| Radio tarjeta | **21 px** |
| Padding tarjeta | **15 h / 13 v** |
| Icono sol (círculo) | **35 px**, glifo **19 px** |
| Texto principal tarjeta | **17 px**, w700 |
| Texto secundario | **13.25 px**, dos líneas, **1 px** entre líneas |
| Zona decorativa derecha | **88 px** ancho; gradiente lineal + círculo difuso (opacidades ~0.14–0.24) |

**Bloque vertical aproximado:** 16 + ~32 + 3 + ~16 (sub) + 17 + 92 ≈ **176 px** (límites del briefing; el asistente alinea arriba y no fuerza 48 px de fila).

## 5. Cambios implementados

- **`ArisHeader`**: título 32 px; subtítulo 13 px; gaps y márgenes reducidos; `IconButton.filledTonal` con `constraints` 36×36, `visualDensity` compact y `iconSize` 20.
- **`GreetingCard`**: alto fijo **92 px**; sin `Material` elevado; sombra muy ligera (`alpha` ~0.028); fondo crema en 3 stops; banda derecha **88 px** con gradiente cálido + mancha radial inferior derecha (`opacity` ~0.22); texto con `padding` derecho **66 px** para no solapar la decoración; sol **35 px**.
- **`HomeScreen`**: `SizedBox(height: 17)` entre cabecera y tarjeta; **dos líneas secundarias** fijas en const: «Dos tareas importantes» / «y un hueco útil a las 11:30.»; saludo principal sigue con **`UserService.getGreetingForNow()`** (p. ej. «Buenos días, José»).
- **`test/widget_test.dart`**: expectativa de marca actualizada de `"Aris"` a **`"aris"`** (minúsculas).
