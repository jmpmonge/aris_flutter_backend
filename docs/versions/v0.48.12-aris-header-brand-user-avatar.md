# v0.48.12 — Ajuste de marca ArisHeader y avatar de usuario

## 1. Contexto

Se ajusta únicamente la cabecera de Home para mejorar la identidad visual de Aris y sustituir el icono IA por avatar de usuario.

## 2. Objetivo

- Dar a «aris» una tipografía de marca (Fraunces vía paquete `google_fonts`).
- Alinear la cabecera con el contenido visual interno de las tarjetas (~30 px desde el borde izquierdo).
- Sustituir el icono de IA por un avatar circular con inicial provisional **J**.
- Conservar el mismo `VoidCallback` de toque que antes (`onAssistantTap`), sin nuevas rutas.

## 3. Decisiones de diseño

- La palabra **aris** usa **`GoogleFonts.fraunces`**: 34 px, `w600`, `letterSpacing` -0.9, `height` 1.0, color `AppColors.primaryDeep`.
- Dependencia **`google_fonts`** añadida solo para cargar Fraunces en runtime; no se modifica `AppTypography` global.
- Padding izquierdo del bloque: **30 px** (referencia tipo 18 + 14 de tarjetas); derecha **18** (`homePageMarginH`).
- Avatar: **40 px**, fondo lavanda `#E5E1FF`, inicial **J** (17 px, `w700`, azul marino `#102A56` / `primaryDeep`).
- No había punto verde decorativo en el widget anterior; el **IconButton** tonal ha sido sustituido por **Material + InkWell** circular.

## 4. Alcance

Incluye:

- `aris_flutter_v0.22/lib/features/home/presentation/widgets/aris_header.dart`
- `aris_flutter_v0.22/pubspec.yaml` (dependencia `google_fonts`)
- Este documento

No incluye: TodaySummaryCard, SuggestionCard, Chat con Aris, navegación, backend, servicios, modelos, tipografía global, headers de otras pestañas.

## 6. Cambios implementados

- Título con Fraunces; subtítulo 14 px, `height` 1.28, color secundario del tema.
- Márgenes: `fromLTRB(30, 18, 18, 0)`.
- Derecha: avatar circular con **J**; mantiene `onAssistantTap` si no es null.

## 7. Pendientes
