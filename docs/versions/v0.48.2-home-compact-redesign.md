# v0.48.2 — Rediseño compacto de Home completa

## 1. Contexto

v0.48.0 inició el rediseño visual de Home.

v0.48.1 compactó el bloque superior.

v0.48.2 extiende el criterio compacto a toda la Home.

## 2. Objetivo

Rediseñar la Home completa con proporción más cercana a NotebookLM: tarjetas anchas, bajas y densas.

## 3. Decisión de diseño

Las tarjetas deben aprovechar más el ancho disponible y reducir altura, márgenes y separación vertical para mostrar más información útil en pantalla.

## 4. Alcance

Incluye:

- Header.
- GreetingCard.
- SuggestionCard.
- TodaySummaryCard (HOY).
- LatestArisActionSection + LocalActionCard (compact).
- RecentConversationCard.
- ChatInputBar (Inicio).
- Ajustes visuales de NavigationBar (tema global).

No incluye:

- Backend.
- Servicios.
- Modelos.
- Endpoints.
- GPT.
- Cambios funcionales.

## 5. Cambios implementados

- **Espaciado global Home**: márgenes laterales `homePageMarginH` (16 px), separación vertical entre bloques `homeSectionGap` (12 px), sombras de tarjeta Home más ligeras (`shadowBlurHomeCard`).
- **ArisHeader**: marca ~30 px, subtítulo 13 px, margen lateral 16 px, menos aire superior.
- **GreetingCard**: altura ~88 px, radio 20 px, padding 12 px, sol ~33 px, texto principal ~16.5 px, franja foto más estrecha (`fit` + degradado multistop para fundir con el panel sin corte duro).
- **SuggestionCard**: altura fija ~76 px, radio 18 px, etiqueta ~11.5 px, cuerpo 14 px, sombra reducida.
- **TodaySummaryCard**: lista continua (eventos → tareas → notas) sin bloques EVENTOS/TAREAS/NOTAS; filas 13.75 px, iconos 18 px; título HOY 16 px / 700.
- **Última acción / Reciente**: márgenes 16 px, sombras tipo Home, Reciente con altura de lista interna 200 px y separadores más tight.
- **LocalActionCard** (solo `compact: true`): padding y sombra más compactos, radio 20 px.
- **ChatInputBar**: márgenes 16 px, altura mínima ~50 px, campo con radio 20 px y texto/hint 14 px; botón mic ~46 px (**solo UI**).
- **Tema**: NavigationBar altura 56 px, etiquetas 12 px (iconos 24 px sin cambio).
