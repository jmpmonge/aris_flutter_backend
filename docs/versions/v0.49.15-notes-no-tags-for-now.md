# v0.49.15 — Vista Notas: sin etiquetas ni hashtags por ahora

## 1. Contexto

La pantalla Notas necesitaba cerrar la decisión sobre etiquetas. Se decide no introducir todavía tags, hashtags ni chips de clasificación visibles.

## 2. Objetivo

- No mostrar etiquetas ni hashtags en Notas.
- No incluir campo de tags en la creación manual.
- Mantener la pantalla limpia y centrada en escribir, listar y usar Aris.

## 3. Decisiones de diseño

- Eliminada la sección «Notas rápidas» con `ActionChip` (sustituto visual de etiquetas frecuentes).
- `LocalActionCard` en notas ya no muestra chip de `noteCategory`.
- El lienzo manual sigue con solo título y cuerpo.

## 4. Alcance

Incluye:
- `notes_screen.dart`
- `local_action_card.dart` (solo ocultación de categoría en tipo nota)
- `manual_note_canvas_sheet.dart` (comentario)
- Este documento.

No incluye: backend, modelos, GPT, rediseño global.
