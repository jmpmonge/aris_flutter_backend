# v0.49.14 — Vista Notas: lienzo manual limpio, botón + circular y único input inferior para Aris

## 1. Contexto

La pantalla Notas necesitaba cerrar la ambigüedad entre creación manual, búsqueda y canal conversacional con Aris. También necesitaba abandonar el lenguaje de formulario en la creación manual.

## 2. Objetivo

- Eliminar el buscador superior.
- Dejar arriba solo un botón + circular.
- Hacer que la creación manual abra un lienzo limpio de nota.
- Mantener el input inferior como único canal para Aris.

## 3. Decisiones de diseño

- `AppHeader` con `IconButton.filledTonal` (+) como única acción manual visible.
- `ManualNoteCanvasSheet`: pantalla lienzo con título (jerarquía alta), línea azul fina y cuerpo multilínea sin bordes de formulario.
- Sin `AppSearchBar`; búsqueda conceptualmente en el input de Aris.
- Placeholder inferior: «Pide a Aris crear o buscar notas…».

## 4. Alcance

Incluye:
- `notes_screen.dart`
- `manual_note_canvas_sheet.dart`
- delegación en `local_action_form_sheet.dart`
- Este documento.

No incluye: backend, GPT, Home, Calendario, Tareas, rediseño global.
