# v0.49.20 — Vista Tareas: entrada manual más compacta, sheet alto y acento naranja solo en metadatos

## 1. Contexto

La entrada manual de tarea ya tenía mejor estructura, pero todavía necesitaba un refinamiento visual en color, iconografía y superficies de texto.

## 2. Objetivo

- Quitar icono decorativo de tarea dentro del editor.
- Dejar el botón principal en el color normal de la app.
- Reservar naranja para fecha, hora y prioridad activas.
- Refinar campos de texto con mejor radio y padding.

## 3. Decisiones de diseño

- Cabecera: solo cerrar.
- CTA: `FilledButton` con color del tema (primary).
- Metadatos activos: `TaskManualEditorAccent.metaActive` (#F4A261).
- Título y notas en superficies redondeadas con padding interno.

## 4. Alcance

Incluye:
- `manual_task_editor_page.dart`
- Este documento.

No incluye: backend, lista de tareas, input de Aris.
