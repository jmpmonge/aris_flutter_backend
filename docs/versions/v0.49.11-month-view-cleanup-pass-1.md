# v0.49.11 — Vista Mes: limpieza de textos técnicos/mock y coherencia con el Calendario ya refinado

## 1. Contexto

La vista Mes seguía mostrando textos técnicos y mock que ya no encajan con el nivel visual alcanzado en Semana y Día.

## 2. Objetivo

- Eliminar ruido técnico/mock.
- Limpiar el encabezado de Mes.
- Dejar el rótulo del mes y el detalle del día seleccionado con un tono limpio.
- Mantener la cuadrícula y la lógica actual.

## 3. Decisiones de diseño

- `AppHeader` sin subtítulo técnico en ninguna pestaña de Calendario.
- Sin franja «Vista mes · … mock» bajo el segmentador.
- Rótulo de mes: «Mayo 2026» (`titleSmall`, `onSurface`).
- Detalle: «Día 22» y «Sin eventos para este día.»

## 4. Alcance

Incluye:
- `calendar_screen.dart`
- `calendar_body_views.dart` (`CalendarMonthView`)

No incluye: backend, Día, Semana, cuadrícula, input.
