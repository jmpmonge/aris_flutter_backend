# v0.48.19 — Ajuste de padding y radio en interacción de eventos de calendario

## Objetivo

Ajustar el hover/pressed de eventos de calendario en `TodaySummaryCard` para que tenga más padding, esquinas redondeadas (cápsula suave) y envuelva **hora + punto + textos** sin quedar pegado a las letras.

## Cambios

- **Archivo modificado:** `aris_flutter_v0.22/lib/shared/widgets/today_summary_card.dart`
- **Padding aplicado:** horizontal **9** px, vertical **7** px (dentro de la zona interactuable de cada fila).
- **BorderRadius:** **14** px en `Material` + `InkWell`.
- **Color hover/pressed:**
  - Claro: hover `#EAF3FF`, pressed `#DDEBFF` (con alpha ~0.88–0.90).
  - Oscuro: hover `#10243F`, pressed `#1A2F4A` (con alpha ~0.82–0.88).
- **Overlay:** `WidgetStateProperty` (`overlayColor`) en lugar de splash/highlight amarillos viejos.
- **Altura de fila:** `_eventRowHeight` = **66** px (contenido 52 + padding vertical 14), sin cambiar el layout interno de hora/punto/título respecto a la fila interior.
- **Hueco entre filas:** **4** px (`_eventRowGap`) para que los hover no se solapen; la línea vertical usa `(n - 1) * (rowH + gap) - 2 * trim`.
- **Timeline:** el eje horizontal de la línea incorpora el padding izquierdo del Ink (`inkPadH + tw + (cw - lineW) / 2`); el centro vertical del punto usa `inkPadV + dotPadTop + dotSize/2` para mantener la alineación con la spine.
