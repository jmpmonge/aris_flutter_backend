# v0.48.29 — Icono TAREAS coherente y compactación real de headers HOY/CHAT

## 1. Contexto

La tarjeta HOY ya está estructurada correctamente (eventos, divisor, TAREAS, lista). Quedan ajustes de coherencia: el icono de TAREAS debe coincidir con la botonera inferior y los headers HOY/CHAT seguían demasiado altos porque `ConstrainedBox(minHeight)` + cajetín chevron grande forzaban ~38–42 px visuales.

## 2. Objetivo

- Usar en TAREAS el mismo `IconData` que la pestaña Tareas (`Icons.task_alt_outlined`).
- Reducir la altura visual real de los headers HOY y CHAT CON ARIS (~34 px).
- Mantener intacta la timeline y la lógica funcional.

## 3. Decisiones de diseño

- Constante compartida `kAppNavTasksTabIcon` en `app_bottom_navigation.dart` (= `AppNavigationShell` destino Tareas, campo `icon`).
- TAREAS mantiene icono naranja `#F59E0B` / `#FDBA74`.
- Headers: sin `ConstrainedBox(minHeight)`; padding vertical 4 px; chevron 26×26 (icono 22 px); `borderRadius` 13.
- Altura visual objetivo documentada: `homeCardHeaderVisualHeight` = 34 px.
- Timeline sin cambios (v0.48.27).

## 4. Alcance

Incluye:
