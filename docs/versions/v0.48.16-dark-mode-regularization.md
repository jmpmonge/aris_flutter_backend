# v0.48.16 — Regularización visual del modo oscuro

## 1. Contexto

El modo claro se mantiene estable. Esta versión corrige únicamente colores problemáticos del modo oscuro.

## 2. Objetivo

- Quitar verdes innecesarios en modo oscuro.
- Regularizar SuggestionCard.
- Regularizar colores de chat.
- Mejorar contraste de “aris”.
- Integrar mejor el avatar “J”.

## 3. Decisiones de diseño

- En modo oscuro, SuggestionCard se integra con el sistema de tarjetas (`#1A1D26`, borde `#2A2F3A` suave, texto título `#E8ECF4`, cuerpo `#C3CAD6`, icono lavanda `#B8AEFF`).
- El verde se reserva solo para estados claros de completado o validación, no para tarjetas generales en oscuro.
- Chat usa tonos oscuros neutros y lavanda suave (`#B8AEFF`), sin verde en burbujas ni chips; usuario `#263044`, Aris `#1A1D26`.
- “aris” usa un azul claro de alto contraste (`#DCE8FF`).
- El avatar “J” deja de usar fondo blanco/lavanda claro; fondo `#2B2547`, letra `#E8ECF4`, borde `#3A4260` opcional.

## 4. Alcance

Incluye:

- `aris_flutter_v0.22/lib/shared/widgets/suggestion_card.dart` — solo rama `Brightness.dark`.
- `aris_flutter_v0.22/lib/shared/widgets/recent_conversation_card.dart` — cabecera, burbujas, chip de intent, loader “escribiendo”.
- `aris_flutter_v0.22/lib/features/home/presentation/widgets/aris_header.dart` — wordmark, subtítulo oscuro, avatar.
- Este documento.

No incluye:

- modo claro (colores previos preservados en cada widget);
- backend, servicios, modelos, GPT;
- rediseño general de Home;
- navegación inferior ni input inferior.

- **SuggestionCard:** en oscuro, fondo `#1A1D26`, borde `#2A2F3A` (~42% opacidad), etiqueta `#E8ECF4`, cuerpo `#C3CAD6`, icono `#B8AEFF`; claro sin cambios.
- **RecentConversationCard:** burbujas Aris/usuario `#1A1D26` / `#263044`; borde de burbuja `#2A2F3A`; texto principal `#E8ECF4`, secundario `#C3CAD6`; sombra usuario neutra (negro); título “CHAT CON ARIS” `#E8ECF4`; chip de intent en oscuro fondo violáceo suave y texto/borde lavanda; loader espera lavanda.
- **ArisHeader:** wordmark oscuro `#DCE8FF`; subtítulo oscuro `#C3CAD6`; avatar círculo `#2B2547`, letra `#E8ECF4`, borde `#3A4260` suave.
