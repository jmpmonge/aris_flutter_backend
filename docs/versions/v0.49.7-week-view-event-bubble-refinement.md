# v0.49.7 — Vista Semana: rediseñar bloque de evento compacto con icono y etiqueta opcional

## 1. Contexto

La vista Semana ya funciona estructuralmente, pero el bloque visual del evento todavía parecía una pastilla poco cuidada y no transmitía bien una pieza compacta de agenda.

## 2. Objetivo

- Redefinir el bloque del evento semanal.
- Mejorar su contorno, presencia y limpieza visual.
- Permitir icono y etiqueta opcional si encaja bien.
- Mantener compactación y estabilidad visual.

## 3. Decisiones de diseño

- Nuevo `CalendarWeekEventBubble`: franja de acento, superficie elevada, sombra suave, icono en círculo.
- Etiqueta solo si ancho ≥ 46 px y texto ≤ 8 caracteres; si no, solo icono centrado.
- Franja horaria 32 px de alto (antes 30).
- Resolver de badge (v0.49.6) sin cambios de lógica.

## 4. Alcance

Incluye:
- `calendar_week_event_bubble.dart`
- `calendar_body_views.dart` (`_weekEventBlock`)

No incluye: backend, rejilla, Home, Día, Mes, input inferior.

cd aris_flutter_v0.22
