# v0.49.1 — Vista Semana: ajuste de geometría y jerarquía de las celdas diarias

## 1. Contexto

Tras la limpieza inicial del header en v0.49.0, el principal problema visual restante en Semana está en la compresión y la jerarquía interna del bloque de los 7 días.

## 2. Objetivo

- Dar más aire al bloque semanal.
- Mejorar la jerarquía visual dentro de cada celda.
- Ajustar altura mínima y equilibrio general de las celdas.
- Mantener el patrón actual sin rehacer la vista.

## 3. Decisiones de diseño

- Se mantiene el bloque semanal existente (`Row` de 7 `Expanded`).
- No se rehace la vista completa.
- Se prioriza claridad, respiración y escaneabilidad.
- Cabecera del día (letra + número) en franja propia; eventos debajo, tipografía más ligera.

## 4. Alcance

### Cambio 1 — Geometría (`CalendarWeekView`)

- Padding horizontal del bloque: `sm` (más ancho útil para columnas).
- Separación uniforme entre columnas: `SizedBox` de `AppSpacing.xs`.
- Padding interno de celdas: cabecera compacta + zona de eventos con `xs`/`sm`.

### Cambio 2 — Jerarquía interna

- Franja superior con fondo diferenciado para letra (10px, variant) y número (`titleSmall` / `titleMedium` si es hoy).
- `Divider` entre cabecera y contenido.
- Títulos de evento: `labelSmall` 11px, peso 400, color `onSurfaceVariant`.

### Cambio 3 — Altura y equilibrio

- `IntrinsicHeight` + `crossAxisAlignment: stretch` para igualar altura de las 7 celdas.
- `minHeight` 108 en cada celda.
- Zona de eventos en `Expanded` alineada arriba.

### Incluye

- `calendar_body_views.dart` (`CalendarWeekView` únicamente).

### No incluye

- `calendar_screen.dart` (header, Aris, segmentos);
- backend, servicios, GPT, Home, Día, Mes, FAB, nav, input Aris.
