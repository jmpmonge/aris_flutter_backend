# v0.48.43 — Home: Aris compacto conectado a conversación real

## Objetivo

Sustituir el chat completo visible en Home por una **tarjeta compacta de Aris** con input encapsulado, conectada al **mismo flujo conversacional** que ya funcionaba (`POST /message`, `ChatService`, historial híbrido). La Home muestra solo la **última respuesta de Aris**; el historial completo se reserva para un panel inside al tercer envío del usuario o si la respuesta requiere contexto largo.

## Flujo conversacional reutilizado

| Paso | Implementación |
|------|----------------|
| Envío usuario | `Repositories.assistant.sendMessage(text)` → `DefaultAssistantRepository` |
| Cola local | `ChatService.appendUserOnly` + burbuja pendiente + `ApiClient.sendMessage` |
| Respuesta Aris | `ChatService.appendArisBackendMessage` con `uiHint` del backend |
| Lista Home / inside | `Repositories.history.conversationForHome()` (historial backend + cola `ChatService`) |
| Refresh tras POST | `Repositories.prefetchBackendReads()` (hook `afterSuccessfulPost`) |
| Actualización UI | listeners `ChatService.revision` y `Repositories.history.revision` en `HomeScreen` y sheet |
| Micrófono | `Repositories.assistant.sendVoicePendingNotice()` |
| Último texto en tarjeta | `homeLastArisMessageText(...)` sobre `conversationForHome()` |

**Antes en Home:** `RecentConversationCard` + `onFollowUpMessage: Repositories.assistant.sendMessage` + `ChatInputBar` externo en shell.

**Ahora:** `HomeArisReplyCard` con `onSubmit: _sendArisMessage` (mismo `sendMessage`). Sin mock.

## Cambios realizados

- Se elimina el chat completo visible en Home (`RecentConversationCard`, `LatestArisActionSection`, input externo en shell).
- Se crea la tarjeta compacta **HomeArisReplyCard** debajo de `TodaySummaryCard` (separación 16 px).
- La tarjeta muestra solo la **última respuesta de Aris** (máx. 3 líneas, ellipsis); sin burbujas del usuario.
- Mensaje inicial si no hay respuesta: «Estoy listo para ayudarte con tu día.»
- Input encapsulado: micrófono si vacío, enviar si hay texto.
- Se conserva la ingeniería de respuestas anterior (backend + `ChatService`).
- Contador `_homeArisInstructionCount` en Home: 1.ª y 2.ª instrucción → compacta; **3.ª** → `HomeArisChatInsideSheet`.
- También se abre el panel si la respuesta es larga (>280 caracteres, >3 líneas) o trae `ui_hint` no vacío.
- Cabecera ARIS con pill «Activo»; tap en cabecera abre el panel inside.

## Regla de despliegue del chat inside

| Instrucción desde Home | Comportamiento |
|------------------------|----------------|
| 1.ª | Respuesta en tarjeta compacta |
| 2.ª | Respuesta en tarjeta compacta |
| 3.ª | Abre chat grande inside (~88 % altura) |
| Respuesta larga / `ui_hint` | Abre inside en ese envío (heurística) |

**Instrucción** = cada envío del usuario desde el input de la tarjeta compacta en Home.

El panel inside reutiliza `RecentConversationCard` (burbujas completas) y `ChatInputBar` con el mismo callback `onSend` que Home.

## Decisiones de diseño

- Home **no** es un chat histórico; es **respuesta rápida** con una sola intervención activa de Aris.
- El historial completo se reserva para la ventana inside o `AssistantScreen` (cabecera / navegación existente).
- No se muestran burbujas del usuario en Inicio.
- `ChatInputBar` no se modificó; la tarjeta usa input interno ligero con los mismos callbacks de envío.
- Una sola tarjeta, radio grande, borde y fondo coherentes con el tema.
