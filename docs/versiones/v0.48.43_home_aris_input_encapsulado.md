# v0.48.43 — Home: tarjeta Aris con input encapsulado

## Objetivo

Sustituir el chat completo de la Home por una **tarjeta compacta de Aris** con una sola intervención activa y el input integrado, sin burbujas de usuario ni barra externa de escritura.

## Archivos modificados

- `aris_flutter_v0.22/lib/shared/widgets/home_aris_reply_card.dart` (nuevo)
- `aris_flutter_v0.22/lib/features/home/presentation/home_screen.dart`
- `aris_flutter_v0.22/lib/shared/navigation/app_navigation_shell.dart`
- `docs/versiones/v0.48.43_home_aris_input_encapsulado.md`

## Widget creado

- **HomeArisReplyCard**
- Ruta: `aris_flutter_v0.22/lib/shared/widgets/home_aris_reply_card.dart`

## Cambios realizados

- Se deja de usar **RecentConversationCard** en Home.
- Se deja de usar **LatestArisActionSection** en Home.
- Se elimina **ChatInputBar** como barra fija inferior en la pestaña Inicio (`AppNavigationShell`).
- Se crea una tarjeta única de Aris debajo de **TodaySummaryCard**.
- Se muestra una sola intervención activa (mensaje demo).
- El input «Escribe a Aris…» queda dentro de la tarjeta con micrófono a la derecha (enviar si hay texto).
- La cabecera superior de la tarjeta (ARIS + mensaje) abre **AssistantScreen** al pulsar.
- Los archivos `recent_conversation_card.dart`, `latest_aris_action_section.dart` y `chat_input_bar.dart` se conservan para otros contextos.

## Decisiones de diseño

- Home **no** debe ser un chat completo.
- Home muestra solo **una intervención activa** de Aris.
- El input funciona como **respuesta rápida** embebida.
- Conversaciones largas se resuelven en **pantalla completa** (Assistant).
- No se muestran burbujas del usuario en Inicio.
- Input local en la tarjeta (no se modificó `ChatInputBar` para evitar regresiones en la barra fija).
