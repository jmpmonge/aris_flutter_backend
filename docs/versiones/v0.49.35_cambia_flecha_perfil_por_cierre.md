# v0.49.35 — Cambia flecha de Perfil por cierre suave

## Problema detectado

El botón superior de Perfil usaba `chevron_left_rounded` (antes `arrow_back_rounded`). Se confundía con las flechas `chevron_right` de las tarjetas del menú.

## Decisión

- Icono: **`Icons.close_rounded`** (cierre de pantalla auxiliar).
- Mantener círculo suave de v0.49.34 (tamaño 36 px, fondo y borde discretos).
- Misma acción `onClose` → Inicio con botonera visible.

## Archivos modificados

- `aris_flutter_v0.22/lib/features/profile/presentation/profile_screen.dart`
