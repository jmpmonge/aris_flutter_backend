# v0.48.42 — Home: tarjeta única Hoy, Tareas y Mail con límites 2-3-1

## Objetivo

Convertir la tarjeta central de Inicio en un **resumen único de atención diaria**: una sola tarjeta con tres bloques internos (HOY, TAREAS y MAIL) y límites de visibilidad para evitar listas largas en Home.

## Archivos modificados

- `aris_flutter_v0.22/lib/shared/widgets/today_summary_card.dart`
- `docs/versiones/v0.48.42_home_tarjeta_hoy_tareas_mail.md`

## Cambios realizados

- `TodaySummaryCard` integra **HOY**, **TAREAS** y **MAIL** en la misma tarjeta.
- **HOY** muestra como máximo **2** eventos; si hay más, «+ X eventos más» (pulsable si `onOpenCalendar` está definido).
- **TAREAS** muestra como máximo **3** tareas (mantiene orden estable, completadas recientes, expansión y completar); si hay más, «+ X tareas más» (pulsable si `onOpenTasks` está definido).
- **MAIL** muestra **1** correo de vista previa con datos **mock/demo**; «+ X correos más» sin navegación real aún.
- Separadores horizontales suaves entre HOY | TAREAS | MAIL (1 px, margen vertical ~13 px, color `outline` / `outlineVariant` con alpha bajo).
- Cabeceras compactas por sección (icono 18 px, etiqueta 11.5 px, w700, letterSpacing 0.7).
- Estados vacíos: «Sin eventos próximos hoy» y «Sin tareas pendientes».
- **Notas** no forman parte de esta tarjeta ni de Home en esta versión.
- Mail queda como bloque visual preparado; sin backend, servicios ni repositorios nuevos.

## Límites de Home

| Sección | Elementos visibles |
|---------|-------------------|
| HOY     | 2 eventos         |
| TAREAS  | 3 tareas          |
| MAIL    | 1 correo (mock)   |

## Decisiones visuales

- Una sola tarjeta para todo lo que requiere atención hoy (mismo fondo, borde, sombra y padding que `TodaySummaryCard` previo).
- Líneas separadoras internas entre secciones, sutiles en modo oscuro.
- Color por sección en cabecera y enlaces «+ X más»:
  - HOY: azul calendario
  - TAREAS: naranja
  - MAIL: morado / lavanda
- Timeline vertical de eventos solo si hay **2 o más** eventos visibles.
- Espaciado vertical optimizado para que la tarjeta quepa bien en móvil junto al bloque posterior de Aris.
