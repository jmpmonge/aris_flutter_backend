# v0.48.49 — Restaura tarjeta libre de Aris y separa del input fijo

## Versión base

- **v0.48.48** — `HomeArisDockCard` unificado y fijo al pie (header + mensaje colapsable + input en una sola pieza fuera del scroll).

## Problema detectado

En v0.48.48 la tarjeta de Aris quedó **anclada al pie** dentro del dock acordeón. El header y el mensaje dejaron de desplazarse con el scroll y la pieza se percibía como bloque fijo pegado al input, sin aire ni independencia visual.

**Causa técnica:** `HomeArisDockCard` vivía en la `Column` inferior (fuera del `ListView`), con `messageExpanded` ligado al scroll de HOY. Solo el mensaje se ocultaba; la carcasa seguía fija.

## Objetivo

- Input de Aris **fijo** abajo (mismo estilo `arisCardInputDockDecoration`).
- Tarjeta superior **libre**, dentro del scroll normal.
- Separación estable entre tarjeta e input (sin solapamiento ni sensación de bloque único).

## Solución aplicada

1. **`HomeArisReplyCard`** vuelve al `ListView` (debajo de HOY, gap 16 px).
2. **`HomeArisFixedInputBar`** fijo en la `Column`, con `padding.top = homeArisCardToInputGap` (16 px).
3. Tarjeta con **`HomeCardTheme.cardDecoration`** (radio completo) para leerse como tarjeta independiente del dock.
4. **`ListView.padding.bottom`** = `homeArisCardToInputGap` + `homeScrollBottomBreathing` + `safeArea.bottom` para reservar respiro al final del scroll.
5. Eliminados `HomeArisDockCard`, `_arisMessageExpanded` y `_syncArisMessageExpanded`.
6. Restaurado `_preventArisScrollPastTop` y métricas HOY con altura de `HomeArisReplyCard.bodyHeight`.

## Validación

```bash
cd aris_flutter_v0.22 && dart analyze
```

- Input fijo abajo al abrir Home.
- Tarjeta Aris se mueve con el scroll.
- Aire visible entre tarjeta e input (16 px + respiro inferior del listado).
- Sin solapamiento ni tarjeta bloqueada.
