# v0.48.44-fix — Home: Aris como tarjeta acordeón unificada

## Problema detectado

La corrección v0.48.44 separó el mensaje de Aris del input: `CustomScrollView` + `SliverFillRemaining` + `HomeArisContinuityBridge` + `HomeArisFixedInputBar` fuera del scroll. Eso empujaba Aris hacia abajo, dejaba un hueco grande entre `TodaySummaryCard` y la tarjeta, cortaba la parte superior al hacer scroll y pegaba el input contra la navegación inferior como pieza fija desconectada.

## Objetivo

Restaurar Aris como una tarjeta única tipo acordeón: cabecera, mensaje flexible/contraíble e input siempre unidos dentro del mismo `DecoratedBox`, en el flujo natural del `ListView` justo debajo de HOY.

## Archivos modificados

- `aris_flutter_v0.22/lib/features/home/presentation/home_screen.dart`
- `aris_flutter_v0.22/lib/shared/widgets/home_aris_reply_card.dart`
- `aris_flutter_v0.22/lib/shared/widgets/home_aris_layout.dart`
- `aris_flutter_v0.22/lib/theme/home_card_theme.dart`
- `docs/versiones/v0.48.44_fix_home_aris_acordeon.md`

## Cambios realizados

- Eliminación de `Column` + input fijo, `SliverFillRemaining`, `HomeArisContinuityBridge` y `_glueArisBodyToInput()`.
- Eliminación del padding inferior inflado (input + nav) entre HOY y Aris; solo padding al final del scroll.
- `HomeArisReplyCard` vuelve al `ListView` con separación de 16 px tras HOY.
- Input integrado en la tarjeta con `Divider` interno (no corte externo).
- Mensaje con `ConstrainedBox` (min 56 px, max 132 px) y `maxLines: 3`.
- Una sola decoración `HomeCardTheme.cardDecoration` (radio y borde completos).
- Se mantiene `_clampArisCardTopGap`, callbacks, chat inside y envío a backend.

## Decisiones de diseño

- Aris no debe parecer una tarjeta partida.
- El input pertenece visualmente a Aris; no hay input global fijo en esta versión.
- Si falta espacio, se contrae el bloque de mensaje y el scroll desplaza la tarjeta entera.
- La Home usa scroll natural (`ListView` único).

## Medidas visuales

| Medida | Valor |
|--------|-------|
| Separación HOY → Aris | `AppSpacing.homeSectionGapMax` = **16 px** |
| Altura input | **44 px** (`HomeArisLayout.inputHeight`) |
| maxLines mensaje | **3** |
| Altura mensaje | **56–132 px** (min/max) |
| Padding interno tarjeta | **16 px** horizontal; **15/12 px** vertical |
| Padding inferior scroll | **56 px** nav + safe area + **16 px** extra |
