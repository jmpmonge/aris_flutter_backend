# v0.48.44 — Home: continuidad visual de Aris e input fijo

## Objetivo

Corregir el corte visual entre la tarjeta de mensaje de Aris y el input fijo en Inicio, de modo que ambas zonas se perciban como una sola tarjeta continua, manteniendo el input siempre visible fuera del scroll.

## Problema detectado

El mensaje de Aris vivía en un `DecoratedBox` dentro del `ListView` y el input en otro bloque fijo debajo del `Expanded`. Entre ambos quedaba visible el fondo del scaffold (franja oscura en modo oscuro), porque el área vacía del scroll no compartía superficie ni bordes laterales con la tarjeta. Dos piezas con radios y bordes independientes reforzaban la sensación de tarjeta partida.

## Cambios realizados

- El input sigue siendo fijo y siempre visible (`HomeArisFixedInputBar` fuera del scroll).
- El mensaje de Aris permanece en scroll (`HomeArisReplyCard` en `CustomScrollView`).
- Se añade `HomeArisContinuityBridge` con `SliverFillRemaining` para rellenar el hueco bajo el cuerpo con la misma superficie y bordes laterales que la tarjeta.
- `_glueArisBodyToInput()` alinea el borde inferior del cuerpo con el borde superior del input al hacer scroll.
- Decoraciones coordinadas en `HomeCardTheme`: cuerpo (radio superior + borde inferior), puente (laterales), input (radio inferior, sin borde superior duplicado).
- Separador interno suave (`Divider`) entre mensaje e input; no espacio exterior oscuro.
- Padding inferior del scroll documentado en `HomeArisLayout.scrollBottomPadding` (= input + nav + 12).
- Se mantiene `_clampArisCardTopGap` y la ingeniería de respuestas existente.

## Decisiones de diseño

- Prioridad: input permanente y visible.
- Aris no debe parecer una tarjeta rota: dos piezas técnicas, una pieza visual.
- Opción A (`Column` + scroll + pie fijo) con puente de color en el scroll para eliminar el corte.
- El scroll no debe tapar contenido relevante (padding inferior explícito).
- El input no entra en el `ListView` para no desaparecer al desplazar.

## Medidas visuales

| Medida | Valor |
|--------|-------|
| Separación HOY → Aris | `AppSpacing.homeSectionGapMax` = **16 px** |
| Altura aprox. bloque input fijo | **64 px** (`HomeArisLayout.fixedInputBlockHeight`) |
| Padding inferior scroll | **132 px** (64 + 56 nav + 12 extra) |
| Radio parte superior | `AppSpacing.homeCardRadius` = **22 px** (topLeft/topRight) |
| Radio parte inferior | **22 px** (bottomLeft/bottomRight en input) |
| Separador interno mensaje/input | `HomeCardTheme.sectionDivider` — línea 1 px, sin hueco exterior |
