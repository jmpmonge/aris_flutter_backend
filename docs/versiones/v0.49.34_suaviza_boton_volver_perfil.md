# v0.49.34 — Suaviza botón volver de Perfil

## Problema detectado

El botón de volver usaba `IconButton.filledTonal` con `arrow_back_rounded`, mismo peso visual que el «+» de Tareas/Notas. En Perfil (pantalla auxiliar) resultaba demasiado dominante.

## Decisión

Mantener botón, posición y `onClose`; reducir protagonismo.

## Estilo aplicado

| Antes | Ahora |
|-------|--------|
| `IconButton.filledTonal` | Círculo 36 px con fondo `surfaceContainerHighest` ~26–34 % opacidad |
| `Icons.arrow_back_rounded` | `Icons.chevron_left_rounded` (22 px) |
| Contraste tonal fuerte | Borde `outlineVariant` suave; icono `onSurfaceVariant` ~72 % |

Comportamiento sin cambios: cierra overlay → Inicio + scroll arriba.
