# v0.49 — Refina pantalla Calendario (vista Día) alineada con Home

## Versión base

- **v0.48.48** — Home con tarjeta Aris acordeón e input integrado en dock.
- Calendario usaba `AppHeader`, textos mock/técnicos, `AppCard` genérica y FAB central de Aris en el shell.

## Objetivo

Refinar Calendario (prioridad vista **Día**) para que comparta el mismo lenguaje visual que Inicio: paleta, tarjetas, márgenes, input fijo de Aris y navegación inferior, sin sistema visual paralelo.

## Herencia visual desde Home

| Elemento | Origen en Home |
|----------|----------------|
| Márgenes laterales | `AppSpacing.homePageMarginH` |
| Tarjetas / bordes / sombras | `HomeCardTheme.cardDecoration`, `panelBorder`, `sectionDivider` |
| Tipografía de sección | `HomeCardTheme.sectionTitleStyle` |
| Colores texto / acento | `AppColors.textPrimaryDark`, `textSecondary*`, `calendarBlueDark` |
| Input fijo inferior | `HomeCardTheme.arisCardInputDockDecoration` → widget `ArisFixedInputDock` |
| Fecha natural | `UserService.getHomeDateLine()` (misma línea que Inicio) |
| FAB Aris | Oculto en shell para pestaña Calendario (como Inicio) |

## Cambios realizados

### Encabezado

- Nuevo `CalendarScreenHeader`: título «Calendario», fecha del día, selector Día/Semana/Mes.
- Eliminados subtítulo técnico (PATCH/DELETE), botón + del header y textos «franjas horarias mock».

### Vista Día

- Horas con peso visual reducido (11.5 px, color terciario).
- Separador vertical con `HomeCardTheme.sectionDivider`.
- Eventos en `CalendarHomeEventCard` (misma familia que cards de Inicio).

### Input Aris

- `ArisFixedInputDock` reutilizable (mismo dock que Inicio).
- Placeholder: «Escribe: reunión mañana a las 10».
- FAB del shell desactivado en tab Calendario (`_tabIndex == 1`).

### Bloque Aris / sincronizados

- Secciones «Sincronizados» y «Creados por Aris» con `HomeCardTheme` y microcopy sobrio.
- Empty state integrado en tarjeta Home.

### Semana / Mes

- Márgenes y superficies alineados; títulos sin «mock» ni «simulado».
