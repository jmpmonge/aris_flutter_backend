# v0.49.30 — Botonera con Notas, Tareas y Mail; configuración arriba

## Problema detectado

En v0.49.29, Mail entró en el shell pero **sustituyó a Notas** en la botonera y Perfil ocupaba el quinto tab. La fecha fija volvió a mostrar «Hoy · …» duplicando el título de sección HOY.

## Decisiones

### Botonera inferior (5 pestañas de trabajo)

| Índice | Sección |
|--------|---------|
| 0 | Inicio |
| 1 | Calendario |
| 2 | Tareas |
| 3 | Notas |
| 4 | Mail |

**Perfil/Configuración** sale de la botonera. `ProfileScreen` se mantiene; se abre con push desde Inicio.

### Configuración arriba en Inicio

- Misma fila que la fecha fija.
- Botón **tres puntos** (`more_horiz`) dentro de un **círculo** discreto (32 px), alineado a la derecha.
- `onOpenSettings` → `Navigator.push` a `ProfileScreen` (no rompe el shell al volver).

### Fecha superior

- Solo `{día semana}, {día} de {mes}` — sin prefijo «Hoy ·».
- Padding inferior: `homeFixedDateMinPadding` = 12 px.

### Navegación desde Home

Calendario, Tareas y Mail siguen activando tab en el shell (`_onTabSelected`). Sin sheet ni push para secciones principales.

### Transición

`IndexedStack` + cambio instantáneo de tab (igual que v0.49.29).
