# v0.49.4 — Microanimación mínima en tarjeta Aris de Inicio

## Auditoría previa (resumen)

- `HomeArisReplyCard` no usaba `AnimatedSwitcher` ni animación de contenido.
- Solo `ArisThinkingIndicator` animaba los puntos (1200 ms loop).
- Cambios texto ↔ pensando y entre respuestas eran instantáneos.
- Altura fija `SizedBox(height: 58)` — se mantiene.

## Decisión

- **Sí:** `AnimatedSwitcher` + `FadeTransition`, 210 ms, `Curves.easeOut`.
- **Keys:** `aris-body-thinking` / `aris-body-$activeMessage`.
- **No:** `AnimatedSize`, `AnimatedContainer`, `AnimationController` custom en la tarjeta.

## Archivo modificado

- `aris_flutter_v0.22/lib/shared/widgets/home_aris_reply_card.dart`

## Alcance excluido

- `home_screen.dart`, `_layoutTightenSteps`, HOY, Perfil, navegación, backend.
