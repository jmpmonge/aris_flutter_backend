# v0.49.29 — Mail como sección principal dentro del shell

## Problema detectado

Mail se abría con `showModalBottomSheet` (efecto desde abajo) o, en versiones anteriores, con `Navigator.push` sin botonera. No quedaba al mismo nivel que Calendario o Tareas.

## Decisiones

- **Mail es sección principal** dentro del `IndexedStack` del shell.
- **Botonera:** Inicio · Calendario · Tareas · Mail · Perfil (Notas sale de la barra; la pantalla Notas sigue en el repo pero no es tab principal).
- **Mismo tránsito** que el resto de pestañas: cambio instantáneo de tab (sin slide ni sheet).
- **Desde Home:** el bloque Mail llama `_goToMailTab` → `_onTabSelected(3)`.
- **Pantalla:** `MailScreen` simplificada (placeholder): título, subtítulo, aviso «Próximamente / Sin conexión configurada». Sin APIs ni lógica de correo real.

## Índices de pestaña

| Índice | Sección |
|--------|---------|
| 0 | Inicio |
| 1 | Calendario |
| 2 | Tareas |
| 3 | Mail |
| 4 | Perfil |
