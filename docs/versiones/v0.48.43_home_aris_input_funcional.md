# v0.48.43 — Home: tarjeta Aris funcional con input encapsulado

## Objetivo

La Home sustituye el chat completo por una **tarjeta funcional de Aris** con respuesta rápida: el usuario escribe, envía y la última intervención de Aris se actualiza en la misma tarjeta con lógica mock/local.

- `aris_flutter_v0.22/lib/features/home/presentation/home_screen.dart`
- `aris_flutter_v0.22/lib/shared/navigation/app_navigation_shell.dart` (sin barra externa de input en Inicio)
- `docs/versiones/v0.48.43_home_aris_input_funcional.md`

## Widget creado

- **HomeArisReplyCard**
- Ruta: `aris_flutter_v0.22/lib/shared/widgets/home_aris_reply_card.dart`
- **HomeArisMockReplies** (misma ruta): resolución de respuestas sí / no / otras.

## Cambios realizados

- Se elimina el chat completo de la Home (`RecentConversationCard`, `LatestArisActionSection`, input externo).
- Se deja **una sola intervención activa** de Aris visible (sin burbujas de usuario).
- El input queda **encapsulado** dentro de la tarjeta.
- El input **no queda muerto**: al enviar, limpia el campo y actualiza el mensaje de Aris.
- Respuestas **mock/local** según el texto (sí / no / otro).
- `onOpenFullConversation` abre **AssistantScreen** desde Home.
- No se llama al backend ni a repositorios al enviar desde esta tarjeta en esta versión.

## Comportamiento del input

| Estado | Acción |
|--------|--------|
| Campo vacío | Icono micrófono |
| Campo con texto | Icono enviar |
| Submit (teclado o botón) | Limpia input y actualiza mensaje Aris |

**Respuestas mock:**

- Sí / vale / ok / avísame → «Listo, te avisaré 15 min antes del primer evento.»
- No / déjalo / cancelar → «De acuerdo, no crearé ningún aviso.»
- Cualquier otro texto → «Te he entendido. Puedo ayudarte con eso desde la conversación completa de Aris.»

Pulsar la zona superior de la tarjeta (ARIS + mensaje) abre la conversación completa si hay callback.

## Decisiones de diseño

- Home **no** es un chat completo.
- Home es una **zona de respuesta rápida** con una sola réplica visible.
- Conversaciones largas → pantalla completa (Assistant).
- No se muestran burbujas del usuario en Inicio.
- `ChatInputBar` no se modificó; input local en la tarjeta.
